# Studio Nine - Freelancer Services Template

A premium, product-focused website for service businesses. Minimal, dark, and designed for results.

## Folder Structure
```text
freelancer-services-site/
├── assets/
│   ├── css/
│   │   └── custom.css    # Design system and custom styles
│   ├── js/
│   │   └── main.js       # Interactivity (Mobile menu, FAQ, Footer year)
│   └── img/              # Place your project images here
├── index.html            # Home (Clarity-focused)
├── services.html         # Services & Packages
├── process.html          # Timeline & Deliverables
├── about.html            # Principles & Bio
├── contact.html          # Project Inquiry Form
└── README.md
```

## Local Preview
Just open `index.html` in your favorite browser. No build tools required.

## Deployment (GitHub Pages)
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` branch and `/ (root)` folder.
5. Click **Save**.

## Customization
- **Branding**: Open all HTML files and search/replace "Studio Nine".
- **Colors**: Edit `:root` variables in `assets/css/custom.css`.
- **Contact**: Update the email address in `contact.html`.
- **Images**: Add real images to `assets/img/` and update `src` tags in HTML.
